# SAE-Touiteur_BOURREL_ELASRI_RIGHETTI_CUNY_B

Membres du groupe : Robin Bourrel, Rayan El Asri, Matteo Cuny et Ugo Righetti

Pour lancer l'application touiteur il faut lancer sur Xampp Apache et Mysql puis aller sur localhost/phpmyadmin et créer les tables via le fichier schema_touitteur.sql (fichier en oracle comme demander sur le sujet), 
il faut donc transformer les données en mysql.

Puis, il faut ajouter des données test. Puis lancer le projet depuis l'adresse : http://localhost/SAE-Touiteur_BOURREL_ELASRI_RIGHETTI_CUNY_B/touiteur/index.php sur votre navigateur web.

Enfin, nous avons fait les fonctionnalités suivantes : 

Ugo :
  6. Publier un touite   
  8. La gestion des tags
Robin :
  4. Afficher les touites d'une personne donnée (accès via le clic sur un auteur)  
  9. Le mur d'un utilisateur (page d'accueil regroupant les suivis et tags abonnés en ordre chronologique inverse)   
  14 / 15. Partie administration / rentabilisation (Affichage des influenceurs et des tendances) (comme pas d'authenfication affichage sur la page d'accueil et limitation a 5)
Rayan :
  1. Afficher la liste des touites (en ordre chronologique inverse, version courte)
  3. Paginer la liste des touites
  5. Afficher les touites associés à un tag donné
Matteo :
  2. Afficher un touite en détail 
  7. Évaluer un touite 
  10 / 11. S'abonner à un tag et s'abonner a un utilisateur
